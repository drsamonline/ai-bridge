It drives a tab, not an API

01 · EDITOR

VS Code extension

Panel, diffs, state, settings and commands — everything that touches your workspace. Ctrl+Alt+A opens the chat.

02 · LOOPBACK

Bridge process

A Node process on 127.0.0.1 with a token in ~/.ai-bridge/lock.json. Holds the adapters, the router and the watchdog.

03 · BROWSER

Your signed-in tab

Attached over CDP on port 9222. Never launched by the extension — only the window you opened.

Three parts, all on your machine. The bridge never leaves loopback. Nothing is proxied through anyone's server.

What that buys you

No API keys

Nothing to paste, nothing to leak, nothing to bill. The extension drives the page you're already signed in to.

Your session, your model

The plan you already pay for, and the model you already picked — read straight from the page.

Edits you can refuse

Every change arrives as a proposal. Untick a hunk, accept the rest, one undo takes it all back.

Survives the usage limit

When ChatGPT says you've hit your cap, the context walks to Claude or Gemini by itself — boot prompt first, then only what changed. A badge on the reply tells you it switched.

What it does about tokens

Compression is noise on a terse prompt and a real 20–40% on verbose text. Measured with the project's own counter; identifiers, numbers, negations and code fences are checked to survive.

InputTokensSaved
Polite one-liner34 → 2138%
Terse one-liner8 → 8—
Verbose spec paragraph113 → 8029%
Pasted stack trace83 → 7114%
Code request68 → 5913%

The bigger lever is not compression: context is only attached when your question names a file, a symbol or a code term — a repo bundle costs 500–900 tokens every time.

Install

1 · Download ai-bridge-0.20.4.vsix from the latest release
2 · VS Code → Extensions → … → Install from VSIX
3 · Open the AI tab you are signed in to, then press Ctrl+Alt+A

# the bridge binds to 127.0.0.1 only; the token is written to ~/.ai-bridge/lock.json

Windows, Linux and Android are the supported platforms. There is no macOS or iOS build.
