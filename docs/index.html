What it does about tokens

Measured with the project's own counter, on realistic inputs. Savings that break the prompt are not savings — identifiers, numbers, negations and code fences are checked to survive.

InputTokensSaved
Polite one-liner34 → 2138%
Terse one-liner8 → 80%
Verbose spec paragraph113 → 8029%
Pasted stack trace83 → 7114%
Code request68 → 5913%
Boot prompt975 → 9740%
Repo bundle588 → 37037%

Compression is noise on a terse prompt and a real 20–40% on verbose text and repo context. The bigger lever is not sending context the question doesn't need — a bundle costs 500–900 tokens, and it is only attached when you name a file, a symbol or a code term.

What is proven, and what isn't

This is experimental software. The list on the right matters more than the list on the left.

Proven

  • 600 checks, 20 suites, on every push
  • Three adapters and a fourth custom one, end to end against fixtures
  • Per-hunk edits, locked-decision guard, drift refusal, one-undo applies
  • Boot under 4k with every delta present across five failovers
  • A deliberately broken fixture fails the suite — it detects breakage
  • The breakage report contains no chat content, checked against known fragments

Not proven

  • Live selectors — no adapter has run against the real sites
  • The one-hour memory soak — three minutes passes flat, an hour needs hardware
  • T1 / T2 quality — built and guarded, never run against a real model
  • Windows — the code exists, only Linux has been exercised

Install

Two commands, then attach the browser you are already signed in to.

terminal 
# install the extension
$ code --install-extension ai-bridge-0.20.1.vsix

# open your browser with the debug port on (close it first)
$ chrome --remote-debugging-port=9222

# then, in VS Code
Ctrl+Shift+P  →  AI Bridge: Attach Browser

If the health dot is red, the site changed its page. Press AI Bridge: Export Breakage Report — it carries the host, the selectors tried and the tag/attribute names, and never a word of your conversation.
