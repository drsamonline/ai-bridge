## What this app is

A VS Code extension that brings web-chat AI models into the editor, so you can work without leaving the code.

## What it collects

**Nothing.** No analytics, no telemetry, no crash reporting, no fingerprinting, no advertising identifier and
no email capture.

**Your prompts go to the AI provider you are driving** — ChatGPT, Claude, Gemini or whatever you have signed in to — under that provider's privacy terms, not these. The extension itself sends nothing to the author: no telemetry, no analytics, no crash reporting, no licence check. Its own network code talks to `localhost`, to drive the browser tab over the Chrome DevTools Protocol.

If a prompt contains code or data you cannot disclose, do not send it. The provider's retention rule applies to
what you send, and it is the provider's rule, not this app's.

## What is stored on your device

The extension keeps project state locally so a conversation can survive a new chat. Your browser keeps the session it already had; the extension does not store your credentials.

## Links that leave the app

Documentation and support pages contain ordinary links. Opening one takes you to that site, with its own
privacy policy; the app loads nothing from it.

## Erasing

Clear the app's stored data, or delete the app itself. Nothing is held anywhere else, so there is no other
copy to ask us to remove.

## Changes

If a future version ever adds a request that carries your data, this file changes in the same commit.
